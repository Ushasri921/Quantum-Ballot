# Quantum Ballot 🗳️

Quantum Ballot is a secure and user-friendly college election management system designed to simplify the process of conducting digital elections.

The system allows students to securely log in, view candidates, cast their votes, and view election results. Administrators can manage elections, candidates, users, and monitor voting activity.

## 🚀 Features

- 🔐 Student authentication
- 👤 User registration and login
- 🗳️ Secure online voting
- 👥 Candidate management
- 📊 Election results
- 🛠️ Admin dashboard
- 📝 Audit logging
- 🔒 Protected API routes
- 💾 SQLite database
- ⚡ Fast and responsive React interface
